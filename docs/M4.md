# M4 geometry and height-model sweeps

`uwb/m4_sweeps.py` compares explicitly labeled solver models using one retained measurement dataset per geometry/seed cell. The core implementation is `uwb/m4.py`; M1–M3 schemas and solvers remain independent.

## Controls, bounds and pairing

The sweep API accepts `base_experiment`, `options`, `factor`, `values`, `seeds` and `variants`. Each variant has `label` and an `options` object. Starts, initialization seed, initialization method and estimation mode are common across paired models. Up to four variants can vary height models, optional priors, timing model or solver budget. Bounds are 1–10 distinct values, 1–10 distinct unsigned 32-bit measurement seeds, 1–12 starts per run, 5000 evaluations per start, 40 runs and 240 total starts. Every effective configuration is normalized before a solve.

| Factor | Effective control |
| --- | --- |
| `beacon_count` | Generated layout count, integer 3–8 |
| `vertical_separation` | Generated layout nominal `height_m`; truth tag offset is held fixed, so the actual signed separation depends on that offset |
| `height_spread` | Generated layout `height_spread_m` |
| `coverage` | Path scale with the map held fixed; the reference informative/nearly-collinear path uses its default rectangle |
| `height_prior_sigma_m` | Explicit height-prior standard deviation in metres |
| `beacon_height_model` | Categorical `shared` or `independent` model |

Layout factors reject an explicitly supplied coordinate map rather than silently resizing it. A count sweep uses a generated acquisition order and every-cycle cadence appropriate to each count; homogeneous noise/assumed uncertainty vectors retain their scalar level across counts. A coverage sweep for another reference scenario requires an explicit path so its shape is preserved.

Each value/seed cell generates one experiment. Subsequent variants reuse the first model's saved physical initial geometry through `compatible_initial_geometries`. The helper projects the trajectory into the destination model's height constraints and canonical frame; this differs from silently restarting each model with a fresh initialization. The saved projections are checked during offline validation. Parameterizations can differ, so constrained starts need not have identical coordinate arrays. Truth-near starts explicitly use synthetic truth and are diagnostic; independent starts use measurement inputs and declared knowledge.

Height-prior means and their frames matter. In a known map, the soft prior targets world z. In joint soft/free models, the canonical plane through the first three reference beacons defines the signed height coordinate; the same numeric prior mean is then a distance from that plane, not a statement about surveyed world z. Priors are assumptions and can bias geometry. Below-beacon bounds are a separate model choice from a planar-height model. Unsupported coupled bounds must fail with their explanation, without being presented as a planarity requirement.

## Retained quantities and offline reuse

A version `4.0`, `geometry_sweep` artifact contains normalized controls, every attempted run and start, thresholds, a per-start table and per-value/variant aggregates. Progress snapshots preserve completed attempts. Failures remain in all-start denominators; finite nonconverged geometries remain in error distributions. Selected-start distributions are separate.

The legacy `interpolation_display_rmse_m` and `interpolation_ping_rmse_m` columns contain the combined height-model projection and time-interpolation discrepancy. New source runs additionally export `interpolation_only_*` columns and `model_projection_knot_rmse_m`/`model_projection_map_rmse_m` separately; their aggregate distributions are likewise separate. Older retained tables remain valid without these additive diagnostics. These discrepancies are not rigorous optimizer lower bounds. Unavailable truth-frame diagnostics are exported as null rather than invented zeros.

Tables report optimizer convergence, geometric accuracy, range residuals, trajectory/map/height error, best-fit-plane departure, measurement-only rank, augmented rank, measurement/height-prior objectives and motion/interpolation/timing effects separately. A tilted plane can have substantial z span and almost zero plane departure; z variability alone is not nonplanarity. Rank is local, includes the disclosed parameterization and canonical gauge, and does not establish global uniqueness or eliminate reflections. Augmented rank supplied by a height or motion prior is not additional range information.

The disclosed exact geometry threshold is maximum trajectory and beacon error at most 1e-5 m; the noisy threshold is 0.25 m. Exact range acceptance is maximum residual at most 1e-7 m; noisy low-residual acceptance is normalized RMS at most 2. Geometry, residual and optimizer criteria are independent. Model mismatch and asynchronous interpolation can prevent exact recovery even with zero injected noise.

`validate_artifact`, `save_artifact`, `load_artifact` and `table_csv` verify source runs, accounting, model options, compatible initial projections and derived tables without generating observations or solving. CSV contains one row per attempted start. The effective seed is `(options.seed + measurement_seed) % 2**32`.

## Reproduction

Run `.venv/Scripts/python.exe scripts/validate_m4.py` to produce the six factor sweeps and standalone fixtures for coplanar reflections, below-beacon nonplanar fitting, noncoplanar height recovery, tilted/warped paths, planar mismatch, prior bias, shared/independent map heights, rank loss, asynchronous acquisition and forced nonconvergence. Every fixture is saved before its assertions. Checkpoints retain completed sweep attempts; a failed validation retains an incomplete summary and its artifacts. The complete acceptance summary is written only after all checks pass.

Run `.venv/Scripts/python.exe scripts/benchmark_m4.py` for paired fixed/free known-map benchmarks with 3/8 beacons and 12/24 display samples. Each invocation creates a unique directory under `evidence/m4/`; prior evidence and user histories are never overwritten. Acceptance fingerprints exclude the new M4 directory while checking all pre-existing evidence from earlier milestones and all user runs. Recorded results and limitations belong to the actual generated artifacts and are not inferred from requested controls.

## Measured acceptance (October 14, 2026)

[Completed evidence](../evidence/m4/acceptance_20261014_065254_8317a25a/acceptance_summary.json) contains six factor sweeps, 56 runs and 112 starts, plus 16 standalone fixture runs. All 112 sweep starts converged; 64 met the disclosed exact geometry criterion. The one-evaluation fixture retains both nonconverged estimates. All 409 pre-existing evidence/history files checked by the driver were unchanged. An earlier incomplete attempt is retained separately; the completed record follows correction of a dynamic-beacon observation-generation bug.

Both coplanar whole-path reflection branches produced maximum range residual below 1e-7 m; the reflected branch remains geometrically distinct. Enabling below-beacon bounds with free tag heights selected the lower branch and recovered a path with nonzero best-fit-plane departure, so the bound did not impose planarity. Known-map noncoplanar free-height recovery reached 1.74e-15 m position RMS. The tilted-plane fixture had 0.984 m z span but only 4.52e-16 m plane RMS departure; the warped spatial fixture had 0.217 m plane RMS departure.

Geometry uses the raw canonical truth frame for exact joint fixtures and the surveyed world frame for known maps. `evaluation.raw` explicitly canonicalizes truth using the declared model gauge; it does not compare a 3D canonical estimate directly with untransformed world coordinates. No fitted metric scaling or reflection is used. The eight-beacon asynchronous example converges without accurate recovery; its retained ranks, interpolation/model projection discrepancy and starts make this limitation inspectable.

Planar fitting of an excursion produced 0.242 m position RMS and 0.102 m range RMS while converging. A 0.05 m soft-height prior produced 0.121 m position RMS and 0.0473 m range RMS for the same excursion truth. These measured effects show model/prior bias; lower objective or optimizer success is not a geometry guarantee. The height prior's objective is reported separately from motion-prior and measurement objectives.

[Independent mathematical review](../evidence/m4/independent_math_review.json) checked analytic Jacobians for all 16 known/joint × fixed/shared/soft/free tag × shared/independent beacon combinations against directional central differences; the largest discrepancy was 4.88e-8. It also verified exact measurement/motion/height residual concatenation and invariant independent-joint starts and estimates after changing valid synthetic truth metadata. With a spatial trajectory and coplanar shared-height maps, counts 3, 4 and 5 remained rank deficient (36/39, 39/41 and 42/43); the particular generated maps at counts 6–8 were full rank locally. Spatial tag motion by itself therefore does not establish observability. Diverse independent-height maps at counts 4–8 were full rank for this fixture, which is still a local statement.

[Benchmark records](../evidence/m4/benchmark_20261014_065412_15673b6f/performance_benchmark.json) retain every start for paired fixed/free known-map runs with 0.05 m noise and 0.02 s spacing. Whole-wrapper wall times were 0.178/0.353 s for three beacons at 12/24 display samples and 0.192/0.343 s for eight beacons. These include generation, optimization, table building and checkpoint/export validation; they are measurements of this Windows virtual-environment run, not UI latency guarantees.

The independent review also found that degenerate truth-only canonical-frame metadata could interrupt an independent fit before optimization. The core now retains the measurement fit and discloses unavailable truth-frame evaluation and rank separately; truth-near initialization with an impossible truth frame fails explicitly. Compatible initial projection failures likewise preserve every requested failed start with its explanation, and loading/reexporting the artifact does not retry the solve.

## Trajectory, residuals, gauges and supported constraints

Each knot has controlled time and xyz coordinates. Between adjacent knots, the trajectory is linear in time: `p(t)=(1-a)p_k+a p_(k+1)`, with `a=(t-t_k)/(t_(k+1)-t_k)`. The grid covers the supplied measurement times and display domain; no extrapolation or per-ping independent positions are hidden. Timestamp-aware measurement residuals are `(norm(p(t_assumed)-b_receiver)-range)/sigma`. The grouped approximation replaces the evaluation time by the saved cycle-start reference, using exactly the same ranges. Actual positions/times are synthetic truth annotations, not estimator inputs.

Fixed height sets every knot z to the declared datum. Shared height estimates one common world z in known-map mode; in joint mode it fixes that unobservable absolute datum. Free height estimates every knot z. Soft height adds one disclosed normalized residual `(z_k-target)/height_prior_sigma_m` per knot. Optional motion residuals penalize each interior knot's departure from the time-weighted line through its neighbors, divided by `prior_sigma_m`, in xyz. Neither prior adds measurement information. Separate measurement and augmented Jacobians expose that distinction.

Known maps fix all beacon coordinates in the surveyed world frame. Joint planar models remove horizontal translation and rotation by placing beacon 0 at xy=(0,0) and beacon 1 on positive x. The selected tag datum removes absolute vertical translation. Beacon 2's y sign remains an explicit planar reflection branch. Shared beacon height has one relative z parameter; independent heights have one per beacon. No world orientation is recovered from range-only joint fitting.

Joint soft/free models require a full 3D gauge: translate beacon 0 to the origin; rotate beacon 1 onto positive x; rotate beacon 2 into the positive-y xy plane. These six continuous rigid freedoms are removed, and distance scale is retained. Collinear first-three anchors cannot define this frame. A reflection across the anchor plane still preserves its anchors and all distances when the complete map/tag geometry reflects together; proper rigid alignment cannot hide it. Shared beacon heights constrain all canonical beacon z to zero. Independent heights permit z on the remaining beacons. The soft-prior mean refers to this fitted anchor plane, not surveyed world ground.

Below-beacon inequalities are independent of the height model. In known maps, every free/shared tag knot lies strictly below the minimum surveyed beacon z (a small numerical margin is disclosed in the core). For joint shared-height maps with free/soft tags, canonical tag z is below zero. For joint planar tags, beacon heights lie above the fixed tag datum. Joint free/soft tags with independent beacon heights and below constraints are rejected: the present solver supports box bounds rather than the required coupled inequalities. Shared heights and planarity can be scientifically restrictive even when numerically supported; full local rank does not justify those assumptions or establish global uniqueness.

M4 reuses M3's acquisition and playback controls. Its speed chart is explicitly planar along-path speed; vertical excursions are shown by z/time and plane-departure charts and are not included in that speed trace. This limitation avoids presenting planar speed as full spatial speed. Raw joint scenes transform truth into the declared canonical frame; aligned scenes use proper rigid transforms at scale one, with reflection prohibited. Height/plane diagnostics use aligned world geometry, as labeled.

## Independent vertical-sensitivity check

[`height_sensitivity.json`](../evidence/m4/height_sensitivity.json), reproduced by `scripts/check_m4_height_sensitivity.py`, independently checks `dR/dz=(p_z-b_z)/R` against the core Jacobian. At a coplanar surveyed beacon plane, all first-order vertical derivatives vanish (rank 24/36 for this fixture); range variation still exists at second order, so this singular derivative does not by itself prove a continuous family of exact solutions. At a 0.1 mm gap the full-rank condition number was 60570.8, at 5 cm 121.14, and at 3 m 2.2816. A diverse-height map at the nominal plane restored first-order vertical information (rank 36/36, condition 33.318). Independent analytic derivatives matched exactly and central differences agreed within 2.07e-9. These are local sensitivities of the recorded layouts, not global uniqueness or optimizer recovery claims.

| Map mode | Tag height | Beacon height model | Below-beacon bound |
| --- | --- | --- | --- |
| Known surveyed map | fixed / shared / soft / free | Saved selection is inert; surveyed xyz remain fixed | Supported, subject to fixed-height feasibility |
| Joint | fixed / shared | shared / independent | Supported |
| Joint | soft / free | shared | Supported in canonical plane frame |
| Joint | soft / free | independent | Unsupported coupled inequalities; explicit rejection |

A mathematically supported parameterization is not necessarily identifiable for a given acquisition/geometry. Independent fitting remains available when truth-only canonical evaluation is undefined; evaluation is disclosed unavailable. Truth-near initialization cannot seed from a degenerate truth frame.
