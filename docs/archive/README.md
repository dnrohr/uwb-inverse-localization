# Development archive

Planning, handoff, milestone descriptions and acceptance records are retained here for provenance. They describe the project at the time they were written; completion checklists, test counts, proposed work and old interfaces are historical context.

Use the [current documentation](../README.md) for the application as it exists today. The root [README](../../README.md) describes installation and normal usage.

The original roadmap, requirements and handoff are preserved alongside the staged model and acceptance documents. Relative Markdown links have been adjusted for this location. Paths embedded in historical code blocks or evidence metadata may still reflect the original repository layout. Retained experiments and acceptance evidence remain under `evidence/`; native source modules, schemas and audit filenames keep their existing names for compatibility.
