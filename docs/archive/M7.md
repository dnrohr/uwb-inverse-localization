# M7: Library, partial survey, and conditional uncertainty

M7 adds a unified Library for saved runs, benchmarks, and comparisons; optional partial survey knowledge for joint fitting; and conditional local uncertainty summaries. M7 also packages paired investigations so the measured data, starts, attempts, and assumptions can be reopened together. The Library is available from the persistent **Experiment / Library** navigation. Its metadata index is rebuildable; the saved JSON artifacts remain authoritative.

M7 passed the scoped numerical, integration, preservation and Library visual acceptance checks. See [M7 acceptance status](M7_ACCEPTANCE.md) for the delivered Library behavior and measured limits, and the [survey and uncertainty details](../science/SURVEY_UNCERTAINTY.md).

## Open the application

Keep existing application sessions intact and launch a separate validation server on port 5057:

```powershell
.\.venv\Scripts\python.exe app.py --port 5057
```

Then open [http://127.0.0.1:5057](http://127.0.0.1:5057) and choose **Library** in the persistent top navigation. Library search, filters, sort, page size, page, grouping, and comparison slots are retained while navigating. Selecting an item previews its metadata; use **Open in viewer** to load the saved result. Benchmark parents group children by recorded relationships, and the explicit all-runs view makes child attempts browseable. Import and export actions operate on saved artifacts.

Browsing requests bounded metadata pages (25 by default, 50 maximum). Row previews use indexed metadata only. Full records are loaded and strictly validated at explicit Open, compare, import and export boundaries. A metadata summary is not a substitute for strict source validation. The index can be rebuilt without modifying source JSON. Its change inventory uses file timestamps and size; a same-size edit that preserves timestamps requires a manual rebuild to refresh the summary.

## Survey knowledge and uncertainty

An optional schema-7 survey declares world-frame coordinates in metres. Fixed coordinate masks eliminate selected parameters exactly; uncertain survey blocks use an explicit selected-axis mean and positive-definite covariance in square metres. Those fixed values and priors are declared knowledge, never extracted from synthetic truth. With survey omitted, the M7 solve delegates to the prior M6 behavior and returns the legacy schema-6 result.

The solver does not add a canonical gauge when fitting surveyed world coordinates. Remaining rigid freedoms stay in the free-coordinate Jacobian; unsupported partial/coupled constraints are rejected. Fixed coordinates are constraints, not noisy range observations. Uncertain survey, motion, and height priors are separately accounted from measurement information. A finite covariance is only available for supported converged Gaussian fits with full augmented local rank and no active/near-active bounds or zero predicted ranges. Robust fits and unsupported or misspecified cases retain diagnostics and explain why intervals are unavailable.

Any available covariance is a local linear Gaussian approximation conditional on the declared noise, prior, selected-mask, and model assumptions. Full local rank does not establish uniqueness, and local intervals do not cover undiscovered reflected or other distant solutions. Coverage results are finite-sample diagnostics for the stated simulation design, not general calibration claims.

`evidence/m7/library_20261015T185641Z/measurements.json` reports metadata-only backend measurements on Windows/Python 3.12.10. Current history (909 files) took 24.19 s to scan cold; warm query median was 19.04 ms (maximum 22.98 ms), with a 25-row first page and 43.9 KB response. The 10,000-record fixture is not a set of numerically valid experiments. These measurements do not establish application startup time, DOM size, browser render latency, or visual usability; no claim is made that indexing removes cold-scan cost.

The M7 work preserves the M0–M6 numerical and persistence contracts. Single-run optimizer internals are not checkpointed, and permanent-write durability is not guaranteed. No external push or publication is part of this delivery.


## Measured survey gains and losses

Three variants use identical saved observations and identical world physical starts (three attempts each). All converged, but these starts did not reliably find the desired world geometry. All-start median errors in metres are:

| Declared knowledge | Trajectory RMSE | Map RMSE | All-range RMSE |
|---|---:|---:|---:|
| Two fixed beacons | 8.5513 | 12.0450 | 0.00770 |
| Same fixed beacons + uncertain remaining survey | 5.5202 | 7.3090 | 0.17676 |
| Same survey with a deliberately biased mean | 5.5186 | 7.3057 | 0.17987 |

The survey priors reduced these median world errors while worsening range fit substantially; convergence and full local rank (22/22) did not establish correct recovery. These are retained basin/reflection diagnostics, not a claim that more survey information always improves an optimizer. With only one fixed beacon, range rank was 24/25 and covariance was withheld for the remaining rigid freedom. The separately tested fully fixed map recovered the noisy planar path and supplied the narrow coverage experiment. Source files retain every start, objective contribution, rejection metric and information spectrum; no proper rigid, scale or reflection alignment hides world error.
