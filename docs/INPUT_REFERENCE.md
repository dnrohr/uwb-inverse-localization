# Input reference

Generated by `scripts/build_user_docs.py` from the GUI help catalog and normalized model defaults. Rebuild after changing either. See [the user guide](USER_GUIDE.md) for workflows and examples.

## Configuration envelope

| Key | Meaning |
|---|---|
| `workspace_version` | Integer `1`; selects the shared draft format, distinct from native run schema_version. |
| `engine` | Explicit `planar`, `timing`, `spatial`, `solver`, `robust` or `survey`. Selecting a different GUI model loads its defaults. |
| `physical`, `assumptions`, `numerical` | Objects holding the generation, fitting and algorithm fields below. |
| `observation_source.kind` | `generate` (default) or `saved`; saved requires exact compatible physical config and retained sigmas. |
| `observation_source.key` | Exact authoritative Library key for saved reuse, e.g. `run:<id>` or an artifact child key returned by Library. Required for saved; not embedded observations. |
| `study.kind` | `single` (default) or `parameter`. Parameter requires generate and a native study engine. |
| `study.factor` | Model-supported factor key; see study-factor table in the guide. |
| `study.variants` | Native uniquely labeled variant array, or omitted for defaults; timing forbids custom variants. See guide examples. |

## Physical fields

| Exact input path | Meaning, units and accepted values | Normalized defaults and models |
|---|---|---|
| `physical.scenario` | Reference experiment: informative coverage, straight-line motion, narrow coverage, or nearly collinear beacons. An explicit path overrides the reference tag path. | planar, timing, spatial, solver, robust, survey: `"informative"` |
| `physical.samples` | Integer 8–100; default 32. Synchronized model: observation epochs. Timing models: display samples; acquisition cycles are controlled by duration and cycle rate. | planar, timing, spatial, solver, robust, survey: `32` |
| `physical.duration_s` | Experiment duration in seconds; default 20. Timing/custom paths allow 0.01–3600 s. Duration and cycle rate must yield 2–100 acquisition cycles. | planar, timing, spatial, solver, robust, survey: `20.0` |

| `physical.path.type` | Custom horizontal path: line, circle, arc, rectangle, figure_eight, or waypoint. Overrides the scenario's tag path; truth height is configured separately. | Optional; only present when added. See explanation and model restrictions. |

| `physical.path.scale` | Dimensionless path scale, 0.01–100; default 1. Scales local path coordinates before rotation and translation. | Optional; only present when added. See explanation and model restrictions. |

| `physical.path.start_angle_deg` | Circle/arc starting angle in degrees, −360 to 360; default 0. | Optional; only present when added. See explanation and model restrictions. |
| `physical.path.arc_angle_deg` | Signed arc sweep in degrees, −360 to 360 with magnitude at least 0.01; default 180. Sign selects direction. | Optional; only present when added. See explanation and model restrictions. |
| `physical.path.waypoints_m` | JSON array of 2–100 local [x,y] points in metres, coordinates −1000 to 1000. Must have positive total length. Scale, rotation and center are applied afterward. | Optional; only present when added. See explanation and model restrictions. |
| `physical.motion.profile` | constant follows uniform path progress; variable includes acceleration, stops and reversal; stationary holds position. This changes synthetic truth, not an estimator velocity input. | timing, spatial, solver, robust, survey: `"constant"` |
| `physical.motion.speed_scale` | Dimensionless path-progress speed multiplier, 0–10; default 1. Zero stops motion; progress is clipped at path endpoints. | timing, spatial, solver, robust, survey: `1.0` |
| `physical.acquisition.beacon_order` | JSON permutation of every zero-based beacon ID, e.g. [0,1,2,3]. Determines sequential ping offsets within each cycle. | timing, spatial, solver, robust, survey: `[0, 1, 2, 3]` |
| `physical.acquisition.cycle_rate_hz` | Positive acquisition cycles per second, at most 10000. floor(duration × rate + 1e-10) + 1 must be 2–100. Default for 32 samples over 20 s is 1.55 Hz. | timing, spatial, solver, robust, survey: `1.55` |
| `physical.acquisition.spacing_s` | Seconds between beacon pings within a cycle, 0–10000; default 0. Nonzero spacing makes pings asynchronous even in the same cycle. | timing, spatial, solver, robust, survey: `0.0` |
| `physical.acquisition.jitter_s` | Uniform acquisition-time jitter half-width in seconds, 0–10000; default 0. Adds a draw from [−jitter,+jitter] to actual ping time and therefore changes true tag position. | timing, spatial, solver, robust, survey: `0.0` |
| `physical.acquisition.timestamp_offset_s` | Offset added to supplied estimator timestamps in seconds, −10000 to 10000; default 0. Distinct from actual acquisition time and packet delivery latency. | timing, spatial, solver, robust, survey: `0.0` |
| `physical.acquisition.timestamp_jitter_s` | Uniform supplied-timestamp jitter half-width in seconds, 0–10000; default 0. Adds a draw from [−jitter,+jitter] after acquisition time and clock offset; models error in the estimator's time input. | timing, spatial, solver, robust, survey: `0.0` |
| `physical.acquisition.delivery_latency_s` | Nonnegative delivery delay in seconds, up to 10000; default 0. Changes delivery metadata, not measurement geometry or acquisition timestamps. | timing, spatial, solver, robust, survey: `0.0` |
| `physical.acquisition.missing_probability` | Independent acquisition missing-ping probability, 0–1; default 0. Missing pings never enter the estimator; separate from contamination dropout and fitted rejection. | timing, spatial, solver, robust, survey: `0.0` |
| `physical.acquisition.beacon_every_cycles` | JSON array of integer cycle strides 1–100, one per beacon. [1,1,1,2] acquires beacon 3 every second cycle. | timing, spatial, solver, robust, survey: `[1, 1, 1, 1]` |

| `physical.beacon_layout.geometry` | equal uses one beacon height; diverse spreads heights; near_collinear and collinear reduce horizontal geometry. Explicit coordinates override generated layout. | spatial, solver, robust, survey: `"equal"` |
| `physical.beacon_layout.height_m` | Nominal generated beacon height in metres, −1000 to 1000; default 3. Not a height supplied to a joint estimator. | spatial, solver, robust, survey: `3.0` |
| `physical.beacon_layout.height_spread_m` | Total generated beacon height spread in metres, 0–100; default 1. Used only for diverse layout, distributed symmetrically around nominal height. | spatial, solver, robust, survey: `1.0` |
| `physical.beacon_layout.baseline_scale` | Dimensionless horizontal beacon-map scale, 0.001–100; default 1. Does not scale tag path or explicit coordinates. | spatial, solver, robust, survey: `1.0` |
| `physical.beacon_layout.coordinates_m` | Optional finite JSON array of count XYZ points in metres. Overrides generated beacon coordinates. Use the optional geometry editor to remove it. | Optional; only present when added. See explanation and model restrictions. |
| `physical.truth_height.type` | Synthetic tag Z profile: planar is constant; tilted is an X-dependent plane; excursion is sinusoidal; spatial adds a higher-frequency vertical component. Independent of estimator height assumptions. | spatial, solver, robust, survey: `"planar"` |
| `physical.truth_height.offset_m` | Synthetic tag-height offset in metres, −1000 to 1000; default 0. Applies to all truth-height profiles. | spatial, solver, robust, survey: `0.0` |
| `physical.truth_height.amplitude_m` | Vertical excursion scale in metres, 0–100; default 0.3. Used for excursion/spatial truth; spatial combines harmonics and can exceed this amplitude. | spatial, solver, robust, survey: `0.3` |
| `physical.truth_height.tilt_deg` | Synthetic plane tilt in degrees, −80 to 80; default 10. Tilted truth adds tan(tilt) × (x − 5) metres to the height offset. | spatial, solver, robust, survey: `10.0` |
| `physical.contamination.nlos.prevalence` | NLOS burst-onset probability per eligible beacon per cycle, 0–1; default 0. Overlapping duration windows mean realized contaminated fraction may exceed this value. | robust, survey: `0.0` |
| `physical.contamination.nlos.magnitude_m` | Positive injected NLOS range bias in metres, 1e-9–100; default 1. Synthetic labels are evaluation references and never tell the estimator what to reject. | robust, survey: `1.0` |
| `physical.contamination.nlos.burst_duration_cycles` | Integer NLOS burst length 1–100 cycles; default 1. Each onset marks this many forward cycles, clipped at the experiment end. | robust, survey: `1` |
| `physical.contamination.nlos.affected_beacons` | JSON array of distinct zero-based beacon IDs eligible for NLOS; default all beacons. Empty array disables NLOS on every beacon. | robust, survey: `[0, 1, 2, 3]` |
| `physical.contamination.offsets_m` | Fixed range bias in metres: scalar or one JSON entry per beacon, −100 to 100; default all zero. These offsets are injected, not estimated calibration parameters. | robust, survey: `[0.0, 0.0, 0.0, 0.0]` |

| `physical.contamination.correlation` | AR(1) correlation between adjacent cycle indices, −0.999 to 0.999; default 0. Independent streams per beacon; not correlation per elapsed second. | robust, survey: `0.0` |

## Assumptions fields

| Exact input path | Meaning, units and accepted values | Normalized defaults and models |
|---|---|---|
| `assumptions.assumed_std_m` | Assumed range SD in metres: scalar or one JSON value per beacon. Strictly positive; timing and later models allow 1e-6–1000; default 0.05. Sets residual weights, not injected noise. Immutable when reusing saved observations. | planar, timing, spatial, solver, robust, survey: `[0.05, 0.05, 0.05, 0.05]` |
| `assumptions.mode` | joint estimates beacon map and trajectory; known_map fixes the complete explicitly surveyed beacon map. Known-map fitting uses declared knowledge unavailable to joint fitting. | planar, timing, spatial, solver, robust, survey: `"joint"` |
| `assumptions.timing_model` | timestamp_aware evaluates piecewise-linear trajectory at supplied ping timestamps; grouped assigns pings to cycle-start positions. Grouped is an approximation for asynchronous measurements. | timing, spatial, solver, robust, survey: `"timestamp_aware"` |
| `assumptions.knot_spacing_s` | Trajectory knot interval in seconds, 0–10000; default 0 uses the cycle grid. Controls estimator trajectory resolution; at most 150 knots are supported. | timing, spatial, solver, robust, survey: `0.0` |
| `assumptions.prior_sigma_m` | Motion smoothness prior SD in metres, 0–10000; default 0 disables. Positive values add prior residuals; smaller means stronger smoothing. Measurement and augmented rank are reported separately. | timing, spatial, solver, robust, survey: `0.0` |
| `assumptions.tag_height_model` | fixed sets every tag Z to the datum; shared estimates one tag height; soft estimates knot heights with a Gaussian height prior; free estimates unrestricted 3D knot heights. | spatial, solver, robust, survey: `"fixed"` |
| `assumptions.beacon_height_model` | shared estimates a common beacon height; independent estimates separate beacon heights. Survey model requires independent. This is an estimator assumption, separate from generated height diversity. | spatial, solver, robust: `"shared"`; survey: `"independent"` |
| `assumptions.fixed_tag_z_m` | Tag Z datum or soft-prior target in metres, −1000 to 1000; default 0. Meaning depends on tag-height model and frame; it does not change synthetic truth. | spatial, solver, robust, survey: `0.0` |
| `assumptions.height_prior_sigma_m` | Soft tag-height prior SD in metres, 1e-6–1000; default 0.2. Smaller values impose a stronger prior; relevant to soft height model. | spatial, solver, robust, survey: `0.2` |
| `assumptions.below_beacons` | Impose supported below-beacon height bounds. Joint independent beacon heights with free/soft tag heights require unsupported coupled inequalities and reject. This is physical knowledge, not a display option. | spatial, solver, robust, survey: `false` |
| `assumptions.loss` | gaussian is least squares; huber, soft_l1 and cauchy downweight large standardized range residuals; hard_rejection fits a Gaussian pilot then refits retained ranges. Priors remain quadratic. | robust, survey: `"gaussian"` |
| `assumptions.loss_scale_sigma` | Robust range-loss scale in units of assumed sigma, 1e-6–1000; default 2. Controls robust transition size; it is not a distance in metres. | robust, survey: `2.0` |
| `assumptions.rejection_threshold_sigma` | Hard-rejection cutoff in assumed-sigma units, 1e-6–1000; default 3. Pilot residuals select retained observations. Pilot and final fit statuses remain separate. | robust, survey: `3.0` |
| `assumptions.weight_decision_threshold` | Influence-weight flag threshold 0–1; default 0.5. Flags weights below this value for diagnostics; changing it does not define the robust objective or rejection cutoff. | robust, survey: `0.5` |
| `assumptions.uncertainty.enabled` | Enable conditional local uncertainty for supported survey fits; default true. Unsupported assumptions produce an explicit withheld reason. | survey: `true` |
| `assumptions.uncertainty.range_model` | Supported declaration: independent_gaussian_known_sigma. Intervals condition on saved range sigmas, chosen model, constraints and priors; robust curvature is not calibrated covariance. | survey: `"independent_gaussian_known_sigma"` |
| `assumptions.uncertainty.rank_rtol` | Relative singular-value rank tolerance 1e-12–1e-4; default 1e-8. Affects local uncertainty rank decisions, not the fitted objective or global uniqueness. | survey: `1e-08` |
| `assumptions.uncertainty.bound_tolerance_m` | Bound proximity tolerance in metres, 1e-12–0.001; default 1e-7. Near-active bounds can withhold local Gaussian intervals. | survey: `1e-07` |

## Survey declaration

`assumptions.survey` contains `frame: "world"`, `units: "m"`, `fixed: []` and `priors: []`. The survey default fixes beacon 0 XYZ to `[0,0,3]`; priors defaults to empty. Each array supports at most 24 rows. Partial survey requires at least one selected coordinate overall. No fixed/prior overlaps or duplicate selected coordinates are accepted.

| Row key | Meaning |
|---|---|
| `beacon_id` | Zero-based beacon ID from 0 through beacon count minus one. A coordinate may occur in only one fixed or prior block. |
| `kind` | Fixed eliminates selected coordinates exactly. Uncertain prior adds a Gaussian survey block using covariance in square metres. Neither is an arbitrary coordinate gauge. |
| `mean_m` | JSON [x,y,z] survey mean in world-frame metres. Only axes selected by the mask constrain the fit, but all three entries must be finite. |
| `covariance_m2` | JSON k × k symmetric positive-definite covariance in m² for the k selected axes, in XYZ order. Example: [[0.01]] means SD 0.1 m. Fixed coordinates have no covariance. |
| `mask` | Include this world-coordinate axis in the survey row. At least one of X/Y/Z must be selected; covariance rows and columns follow selected XYZ order. |

The table Knowledge selector moves rows between `fixed` and `priors`; `kind` is a GUI selector, not a field inside a saved survey row. Prior covariance dimensions match the number of selected axes; unselected mean entries still must be finite.

## Scene layers

| Layer | Behavior |
|---|---|
| `truth` | Show separate synthetic reference trajectory and beacon map. Truth is used for evaluation; independent fitting does not receive it. |
| `estimate` | Show the selected attempt's fitted tag trajectory and beacon coordinates. |
| `initial` | Show the selected attempt's retained physical initial trajectory and beacon map. |
| `errors` | Show displacement vectors between truth and estimated geometry in the selected evaluation frame. |
| `rays` | Show sampled measurement connections (at most 45 pings for robust scenes). Robust ray colors reflect estimator influence weights, not injected NLOS labels. |
| `tagPlane` | Show the tag reference plane when meaningful for the saved model. |
| `beaconPlane` | Show the beacon reference plane when meaningful; independent-height beacons need not occupy a common plane. |

## Optional field applicability

Custom `physical.path` fields are available in all six models. Explicit `physical.beacon_layout.coordinates_m` is available in spatial, solver, robust and survey. Survey rows and `assumptions.uncertainty` are exposed by survey defaults. Parameter-study values/seeds require a model with a native study engine (all except survey). Single-run robust and known-map uncertainty inspection is an explicit supported saved-result operation, separate from editing the survey draft.

## Limits and native formats

The GUI allows 1–12 starts and 1–5000 evaluations per start. Studies allow at most 40 runs and 240 starts, with native factor/variant rules. Numeric fields are finite; JSON rejects NaN/Infinity. Some lower-level Python APIs permit larger budgets than the app. The normalized defaults below describe the app, not a promise that every cross-product of dropdown values is supported.

Native run schemas: planar 1.0; planar study/comparison 2.0; timing 3.0; spatial 4.0; solver 5.0; robust 6.0; survey 7.0 (retaining a schema-6 source experiment). Native `config` contains assumed_std_m; the workspace moves this into assumptions. Native estimator options merge workspace assumptions except assumed_std_m with numerical.
