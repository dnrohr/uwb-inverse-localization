Survey declaration

assumptions.survey contains frame: "world", units: "m", fixed: [] and priors: []. The survey default fixes beacon 0 XYZ to [0,0,3]; priors defaults to empty. Each array supports at most 24 rows. Partial survey requires at least one selected coordinate overall. No fixed/prior overlaps or duplicate selected coordinates are accepted.

Row keyMeaning
beacon_idZero-based beacon ID from 0 through beacon count minus one. A coordinate may occur in only one fixed or prior block.
kindFixed eliminates selected coordinates exactly. Uncertain prior adds a Gaussian survey block using covariance in square metres. Neither is an arbitrary coordinate gauge.
mean_mJSON [x,y,z] survey mean in world-frame metres. Only axes selected by the mask constrain the fit, but all three entries must be finite.
covariance_m2JSON k × k symmetric positive-definite covariance in m² for the k selected axes, in XYZ order. Example: [[0.01]] means SD 0.1 m. Fixed coordinates have no covariance.
maskInclude this world-coordinate axis in the survey row. At least one of X/Y/Z must be selected; covariance rows and columns follow selected XYZ order.

The table Knowledge selector moves rows between fixed and priors; kind is a GUI selector, not a field inside a saved survey row. Prior covariance dimensions match the number of selected axes; unselected mean entries still must be finite.

Scene layers

LayerBehavior
truthShow separate synthetic reference trajectory and beacon map. Truth is used for evaluation; independent fitting does not receive it.
estimateShow the selected attempt's fitted tag trajectory and beacon coordinates.
initialShow the selected attempt's retained physical initial trajectory and beacon map.
errorsShow displacement vectors between truth and estimated geometry in the selected evaluation frame.
raysShow sampled measurement connections (at most 45 pings for robust scenes). Robust ray colors reflect estimator influence weights, not injected NLOS labels.
tagPlaneShow the tag reference plane when meaningful for the saved model.
beaconPlaneShow the beacon reference plane when meaningful; independent-height beacons need not occupy a common plane.

Optional field applicability

Custom physical.path fields are available in all six models. Explicit physical.beacon_layout.coordinates_m is available in spatial, solver, robust and survey. Survey rows and assumptions.uncertainty are exposed by survey defaults. Parameter-study values/seeds require a model with a native study engine (all except survey). Single-run robust and known-map uncertainty inspection is an explicit supported saved-result operation, separate from editing the survey draft.

Limits and native formats

The GUI allows 1–12 starts and 1–5000 evaluations per start. Studies allow at most 40 runs and 240 starts, with native factor/variant rules. Numeric fields are finite; JSON rejects NaN/Infinity. Some lower-level Python APIs permit larger budgets than the app. The normalized defaults below describe the app, not a promise that every cross-product of dropdown values is supported.

Native run schemas: planar 1.0; planar study/comparison 2.0; timing 3.0; spatial 4.0; solver 5.0; robust 6.0; survey 7.0 (retaining a schema-6 source experiment). Native config contains assumed_std_m; the workspace moves this into assumptions. Native estimator options merge workspace assumptions except assumed_std_m with numerical.

Complete default drafts

These are normalized defaults for each explicit model. The GUI initially uses robust or the retained browser-session draft. Optional custom paths/coordinates and parameter-study fields appear only after being added.
