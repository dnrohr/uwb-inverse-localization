ESTIMATOR MODEL

Dimensionless squared-range consistency checks after range normalization. A relaxed tolerance permits approximate noisy proposals; it does not alter the final unsquared range objective.

Gaussian perturbation scale for generated starts; paired supplied starts skip this perturbation.

LM maps finite bounds exponentially and requires strict-interior starts; boundaries are approached asymptotically. h uses metre coordinates; supported shared relative heights select a disclosed positive branch. q represents squared relative height in m², with q ≥ 0 and a positive branch only for supported shared-height geometry.

M6 · MULTIPATH AND ROBUST ESTIMATION

Contamination and robust fit study

Save paired clean/noisy experiments, compare Gaussian and robust fits, and inspect each range decision.

SHARED M4 EXPERIMENT

M6 uses the M4 geometry and M3 timing, motion, noise, starts and evaluation budget. Solver, height coordinate and initializer controls are below. Synthetic clean ranges and labels are saved separately from the estimator input.

CONTAMINATION SOURCES

Isolated outliers and NLOS use the same fixed positive range bias with a one-cycle duration. Longer bursts extend forward from each onset; overlapping bursts merge, so realized affected fraction can differ from onset probability.

The standalone offset source uses the explicit per-beacon vector above. An offset benchmark factor applies the same offset value to every beacon. Listed seeds define paired data instances; they are not additional independent repeats beyond those seeds.

ESTIMATOR AND DECISION RULE

Unsupported models and invalid algebraic starts fail explicitly. LM uses strict-interior exponential bounds and requires retained ranges plus prior rows ≥ parameters. Each rejection stage has the shared evaluation budget; pilot and final status are separate.
